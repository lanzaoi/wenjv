## 1. 环境与配置设计（B0）

### 1.1 配置落点（沿用项目习惯）

现有：`~/.config/inquisitive/backend.env`（Windows 一般是  
`C:\Users\<you>\.config\inquisitive\backend.env`）。

也可支持项目根 `.env`（若代码已读；实现时以 `backend/config.py` 为准，**不要两套真源打架**）。

**禁止**把真 key 写入仓库内文件后 `git add`。

### 1.2 建议新增/使用的环境变量（B0）

名称可在实现时微调，但语义必须覆盖：

```env
# --- 安全 ---
SECRET_KEY=long-random-string

# --- Provider 选择 ---
EMBEDDING_PROVIDER=openai_compatible   # 或 siliconflow；ollama 为可选
CHAT_PROVIDER=openai_compatible        # 或 deepseek；ollama 为可选

# --- Embedding: SiliconFlow (OpenAI-compatible) ---
EMBEDDING_API_BASE=https://api.siliconflow.cn/v1
EMBEDDING_API_KEY=sk-...
EMBEDDINGS_MODEL=BAAI/bge-m3
EMBEDDINGS_DIMENSION=1024

# --- Chat: DeepSeek (OpenAI-compatible) ---
CHAT_API_BASE=https://api.deepseek.com
CHAT_API_KEY=sk-...
CHAT_MODEL=deepseek-chat

# --- Ollama 回退（保留）---
OLLAMA_HOST=http://127.0.0.1:11434
# 当 EMBEDDING_PROVIDER=ollama / CHAT_PROVIDER=ollama 时使用
# EMBEDDINGS_MODEL=chroma/all-minilm-l6-v2-f32
# EMBEDDINGS_DIMENSION=384
```

`.env.example` 或 `docs/env.example` / README 表格：**只有占位符**。

### 1.3 代码触点（实现时必读）

| 区域 | 现状 | B0 目标 |
|------|------|---------|
| `backend/config.py` | `OLLAMA_HOST`, `EMBEDDINGS_*` | 增加 provider/base/key/chat 字段 |
| `backend/vector_store/lance_db.py` 等 | `OllamaEmbeddings` | 按 provider 构建 embedder（OpenAI 兼容或 Ollama） |
| `backend/api/services/chat.py` | `stream_ollama_chat` → `/api/chat` | 增加 OpenAI 兼容 `chat/completions` 流式；Ollama 分支保留 |
| `backend/api/routers/chat.py` | `list_ollama_models` | 云模式可返回配置的默认模型列表或透传；不崩溃 |
| `frontend` | 可能调 models API | 能选到 DeepSeek 模型或默认模型完成问答 |

**B0 不做：** 插件市场、运行时 UI 切换厂商、复杂重试中间件、删光 Ollama 代码。

### 1.4 依赖

- 优先用 **httpx** 已有栈打 OpenAI 兼容 HTTP。  
- 若必须用官方 SDK，再写入 `requirements.txt`，并说明原因。  
- **避免**为 B0 引入半套 LangChain Provider 生态。

## 10. curl 预检示例（人，实现前）

```bash
# SiliconFlow embedding（模型名以控制台为准）
curl -s https://api.siliconflow.cn/v1/embeddings \
  -H "Authorization: Bearer $EMBEDDING_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"BAAI/bge-m3","input":"ping"}' | head -c 400

# DeepSeek chat
curl -s https://api.deepseek.com/chat/completions \
  -H "Authorization: Bearer $CHAT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"ping"}],"stream":false}' | head -c 400
```

预检失败 → **先不要让 Gemini 改业务代码**。
