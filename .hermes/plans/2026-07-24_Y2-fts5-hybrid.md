# Y2 FTS5 Hybrid Upgrade · Plan（方案 C）

> **Tier:** After 1.1 done.  
> **Repo:** `feat/v1.1-g0-hybrid`  
> **Keyword strategy: C = FTS5 primary + Lance LIKE fallback**（不是“删掉 LIKE 只留 FTS5”，也不是三路同时 RRF）

## What

1. 新增 **SQLite FTS5**（`chunks_fts`）+ **jieba** 分词，入库/删除与向量双写。  
2. Hybrid 关键词路默认：

```text
HYBRID_SEARCH_ENABLED=true 时：
  keyword = FTS5 MATCH(…jieba query…)
  if len(keyword) < HYBRID_KEYWORD_MIN_HITS:   # 默认 1
      keyword = merge_unique(keyword, LIKE_results)  # Lance/后端现有子串检索
  final = RRF(vector, keyword)
```

3. **保留 Y1 LIKE 实现**（可改名 `fetch_documents_keyword_like`），作兜底与 `HYBRID_KEYWORD_BACKEND=like` 回退。  
4. **不做** 默认三路同时进 RRF（向量+LIKE+FTS5 全开）。

## Why C

| | 只 FTS5 | 只 LIKE (Y1) | **C: FTS5→LIKE** |
|--|---------|--------------|------------------|
| 中文/排序 | 强 | 弱 | 主路径强 |
| backfill 未完成 | 空结果 | 仍能搜 | **仍能搜** |
| 半截串/怪 query | 可能漏 | 子串能补 | **可补** |
| 复杂度 | 中 | 低 | 中+一点分支 |
| 默认延迟 | 1 次 KW | 1 次 KW | 多数 1 次；兜底 2 次 |

## Architecture

```text
SQLite inquisitive.db
  └── chunks_fts (FTS5)  ← 双写自 add/remove_documents

Vector store (Lance default)
  └── page_content/title/filename  ← LIKE 仍读这里

search_documents:
  vector_results = fetch_documents(...)
  if not HYBRID: return vector
  kw = keyword_fts5(...)
  if len(kw) < MIN_HITS:
      kw = merge(kw, keyword_like(...))   # C
  return RRF(vector, kw)
```

## Config

```text
HYBRID_SEARCH_ENABLED=false          # 总开关，默认关
HYBRID_KEYWORD_BACKEND=fts5_then_like  # fts5_then_like | fts5 | like
HYBRID_KEYWORD_MIN_HITS=1            # FTS5 命中数 < 此值则跑 LIKE 并并入
```

- `fts5`：永不 LIKE（严模式）  
- `like`：等同 Y1（调试/对比）  
- `fts5_then_like`：**Y2 默认后端策略**（仍受总开关约束）

## Sync points（三后端）

| Event | FTS5 | LIKE 数据 |
|-------|------|-----------|
| add_documents | INSERT 分词后文本 | 已在向量行，无需另写 |
| remove_documents / remove_link | DELETE | 随向量行删除 |
| backfill | `fts5_backfill.py` | 不需要 |

## Chinese

- 写入 FTS5 前 jieba 分词；查询同样分词再 MATCH。  
- LIKE 路保持 Y1：简单 split / 子串（兜底不要求 jieba）。

## Constraints

- 默认 `HYBRID_SEARCH_ENABLED=false`  
- jieba → requirements  
- RRF 仍只融合 **两路**：vector + keyword（keyword 可能已是 FTS5∪LIKE）  
- 禁止默认三路独立 RRF  
- FTS5 失败：log + **自动降级 LIKE**（与 min_hits 兜底一致精神）  
- 文档诚实：Y2 = FTS5 主 + LIKE 兜底，非企业搜索引擎
